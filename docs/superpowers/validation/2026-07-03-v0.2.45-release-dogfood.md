## Slice 2b installed-artifact dogfood

Created an isolated temporary fixture with:

- a temporary `HOME` containing a home-side `.memory-lane/memory.jsonl`;
- a project directory with `.memory-lane-scope` set to `migration-scope-v0245`;
- one approved home-stored project memory matching that project scope;
- one pending home-stored project memory matching that project scope;
- an empty home-side `embeddings.jsonl`.

Then ran the installed binary commands:

```sh
HOME="$fixture/home" memory-lane migrate project-local --dry-run --write-plan "$plan" --project "$fixture/project"
HOME="$fixture/home" memory-lane migrate project-local --apply-plan "$plan"
HOME="$fixture/home" memory-lane migrate project-local --apply-plan "$plan" --yes
HOME="$fixture/home" memory-lane migrate project-local --apply-plan "$plan" --yes
HOME="$fixture/home" memory-lane status --json --project "$fixture/project"
```

Results:

- The dry-run wrote a review plan and warned that the plan may contain memory text.
- The dry-run summary reported 2 candidates, 1 approved memory, 1 pending memory, 0 blockers, and 2 rebuild-needed embeddings.
- Applying without `--yes` refused with the expected confirmation message.
- Applying with `--yes` reported `migrated: 2`, preserved the pending status, and reported `reindex needed: 2`.
- Applying the same plan a second time was idempotent and reported `completed before run: 2` with no newly migrated records.
- Final `status --json` reported `legacyProjectMemories.totalLegacyCandidateCount: 0` for the fixture.
