## Verdict

Initial verdict: do **not** exit Phase 21 yet.

The v0.2.35 cleanup and low-signal suppression work is effective, and the cleaned store reduces obvious noise. But validation found one evidence-backed follow-up before Phase 21 exit:

> For broad continuity prompts in the shared Claude/Codex lifecycle path, suppress ordinary recall memory bodies or replace them with canonical continuity read-model context/guidance so stale next-slice memories do not compete with latest continuity state.

The follow-up should be deliberately bounded:

1. Detect existing broad continuity intent in `handleUserPromptSubmit`.
2. Avoid injecting the normal `## Relevant Memory` recall body for that prompt family.
3. Prefer compact continuity guidance/read-model output within existing prompt budgets.
4. Preserve topic-specific recall behavior for non-broad technical prompts.
5. Keep explicit `memory_recall` and `memory_get` full-fidelity.
6. Add contract tests for Claude and Codex hook outputs and generated Pi parity if templates are touched.

Non-goals: retrieval rewrite, auto-consolidation, recall ranking changes, schema expansion, raw transcript indexing, workstream IDs, or memory mutation.
