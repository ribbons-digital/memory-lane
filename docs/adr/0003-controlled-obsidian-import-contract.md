# Controlled Obsidian Import Contract

Memory Lane will implement Obsidian import as an explicit, non-destructive workflow that reads only user-authored Markdown notes from `<vault>/<folder>/imports/` when they opt in with `memory_lane: true`; it will not scan the whole vault, import generated mirror files, or rewrite source notes. Parser and planning logic will live in a separate `@memory-lane/obsidian-import` package, while JSONL remains the source of truth and CLI/core integration applies validated creates or updates through Memory Lane APIs. This chooses safety and clear ownership over convenience because whole-vault scanning, source-note mutation, and mixing import logic into mirror/core would make accidental imports and bidirectional-sync confusion much more likely.
